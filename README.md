
# Train Ticket Booking System

## Masters Project by Shivaraj Chinthakindi
Lewis University, Master of Science in Computer Science

## Project Overview

This web application is a train ticket booking system that allows users to search for trains, view train listings, and check PNR status. The project demonstrates my skills in modern web development using React, TypeScript, and responsive design principles.

## Features

- Intuitive train search functionality with date selection
- Responsive design that works on mobile and desktop devices
- Train listings with filtering options
- PNR status checking capability
- User authentication system

## Technology Stack

This project is built with:

- Vite - For fast development and optimized builds
- TypeScript - For type-safe JavaScript
- React - For building the user interface
- shadcn-ui - For UI components
- Tailwind CSS - For responsive styling
- React Router - For navigation
- Supabase - For authentication and backend services

## Local Development

To run this project locally:

```sh
# Clone the repository
git clone <repository-url>

# Navigate to the project directory
cd train-booking-system

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Main application pages
- `/src/hooks` - Custom React hooks
- `/src/utils` - Utility functions
- `/src/lib` - Library code and utilities
